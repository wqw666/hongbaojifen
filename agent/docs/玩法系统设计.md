# agent 玩法系统 v1 设计（2026-09-04，已获用户确认）

> **2026-09-06 起由「复合玩法唯一化」重做取代（rule_fuhe.py，唯一玩法 + GUI 手动操作台 + 红包开奖），本文仅留档**。现行架构见 [代码架构说明.md §8](代码架构说明.md) 与 agent/README「游戏玩法」。

## 背景

总后台「会员玩法管理」已支持上传玩法文件（任意格式 ≤20MB、status 启停、open 列表/下载），但管理页白屏（bug），agent 侧未接入。redbag/ 迁移包经核查全部为只读红包抓取工具、与自动回复无关（quiz-bot 在老电脑未迁移），决策：**整包不入库**（gitignore），仅本机参考。

目标：agent 作为执行器从总后台拉取玩法文件，加载后对指定「游戏群」内全体成员发言（机器人自己除外）按玩法规则自动回复并 @ 发言者。先做两个测试玩法。

## 用户决策记录

| 决策点 | 结论 |
|---|---|
| redbag/ 处置 | 整包不入库，gitignore |
| 玩法引擎位置 | agent Python 层（GUI 进程内 PlayWorker） |
| 玩法文件格式 | Python 源码，约定入口函数 |
| 触发范围 | 全体群成员（含管理员/群主），**排除机器人自己发言**（防 n+1 自循环） |

## 消息链路

```
QQ 群成员发消息
 → NapCat 插件 play.ts 监听 group message（text）事件
 → 过滤：纯文本、非自己发言、群 ∈ 玩法转发群名单
 → HTTP POST http://127.0.0.1:6101/play/msg
     {group_id, qq, nickname, text}
 → agent GUI 内 PlayWorker（http.server 常驻线程，端口 6101）
 → 规则引擎加载玩法 .py → handle_message(group_id, qq, nickname, text) -> str | None
 → 引擎限流（同 qq 1s 内去重）→ 返回 str 则：
     POST 插件 /play/reply {group_id, at_qq, text}
 → 插件 actions.call('send_group_msg', [at qq, text])
```

- 玩法协议：`handle_message(group_id: int, qq: int, nickname: str, text: str) -> str | None`；None = 不回复；返回 str 自动 @ 发送人。
- 引擎：importlib 动态加载（模块名 hash 化防冲突），文件 mtime 变化自动热重载（总后台重传 → agent 重新下载即生效）；玩法代码异常只记日志不回复不崩；同 qq 1s 去重防刷屏。
- 信任模型：玩法文件由操作员自传，与 NapCat 同机执行，等同操作员执行代码。
- 插件端：新增独立 `plugin/src/play.ts`（转发配置 POST /play/config、消息上报 /play/msg 接收侧在 agent、回复端点 POST /play/reply、GET /play/status）；index.ts plugin_init 挂载；api.ts 红包逻辑零改动。play.ts 自带 playGroups/playCallback 配置存插件 config.json。
- agent 侧转发目标端口固定 6101；GUI 未启用玩法时引擎收到消息直接忽略（不回复）。

## GUI 第 8 个 tab「游戏玩法」

状态行（玩法引擎 运行/停止 | 玩法名@版本 | 游戏群）+ 玩法列表（GET /api/open/rules active，刷新）+ 游戏群号输入 + 启用/停止按钮 + 500 行日志（收到的消息/回复/错误）。

- 启用流程：download_rule(id) 下载 .py 到 `%APPDATA%\QQHongbaoMonitor\plays\` → 试加载（失败当场报错不启用）→ 插件配置转发群 → 引擎处理。
- AppConfig 新字段：`play_rule_id`、`play_rule_name`、`play_group_id`、`play_enabled`；重启 GUI 自动恢复（_startup 时若 play_enabled 则自动重新启用）。
- 线程纪律同现有：网络操作 daemon 线程、UI after(0)；PlayWorker http.server 线程只入队，处理队列 daemon worker 逐个执行；_on_close 清理。
